# Schools and child care (part 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A preset, `schoolsPlugin`, that draws public schools, private schools and child care sites from a plain source the host fills with `getPesticideLocations` features, as school-house badges with Lucide glyphs. It has a card, a list row, a legend, a type filter and count bubbles. A school under the focus point keeps its marker inside the ring, and the focus row drops out. It ships as `@sjvair/map-sdk` `0.1.0-beta.12`.

**Architecture:**
- **The preset wraps `pointsPlugin`** (`src/lib/presets/schools.svelte.ts`), like `collocationSitesPlugin`. It derives a points source from the host's raw features: it adds `refKey`, `name` and `value: null`, and drops types the filter leaves out. It also resolves the type labels through the metadata provider into per-plugin `$state`.
- **No scale.** The derived source's scale is `null`, so `pointsPlugin` draws with `NO_SCALE` (neutral images only). The badge ignores the level color and paints from two new `ThemeColors` keys.
- **Three small core additions**, each general but used only here:
  - `featureclick` carries the clicked feature's source properties;
  - `pointsPlugin` can report whether one of its markers is drawn at a point (`drawnAt`);
  - the focus area asks the map's other plugins through a new `PluginContext.coveredAt`.
- **A new legend kind**, `symbols` (a badge and a label per entry), drawn by `Legend.svelte`.

**Tech Stack:** Svelte 5 runes, TypeScript, MapTiler SDK 4.2 (MapLibre), Vitest (unit, client, browser), Playwright.

**Spec:** `docs/superpowers/specs/2026-11-11-options-toolbar-and-widget-needs-design.md`, section "4. Schools and child care" as revised on 2026-11-12 (d1166a6). Parts 1–3 are merged (`0.1.0-beta.11`).

## Global Constraints

- **Opt-in:** a map without `schoolsPlugin` behaves exactly as in `0.1.0-beta.11`. In particular, a focus point with no plugin implementing `drawnAt` keeps its row, and `featureclick` handlers that ignore `properties` are unaffected.
- **Types:** `"public_school" | "private_school" | "child_care"`. The filter is an allow-list, default all three. A feature with any other `type` is drawn only when no filter is passed (as a school badge, its label from the fallbacks).
- **Badge:**
  - a school-house pentagon, `M12 1.5 L22.5 9.5 V22.5 H1.5 V9.5 Z` in a 24-unit box (viewBox `-1 -1 26 26`), drawn at **20px**;
  - fill is the type's color; outline white (`#ffffff`) at 1.5, then a faint dark edge (`rgba(0,0,0,.35)`) at 0.6;
  - glyph white, stroke 2.6, round caps and joins, the 24-unit Lucide glyph scaled to 16 units at (4, 7).
- **Glyphs (Lucide 1.60.0, ISC):**
  - `school`: `M14 21v-3a2 2 0 0 0-4 0v3`, `M18 4.933V21`, `m4 6 7.106-3.79a2 2 0 0 1 1.788 0L20 6`, `m6 11-3.52 2.147a1 1 0 0 0-.48.854V19a2 2 0 0 0 2 2h16a2 2 0 0 0 2-2v-5a1 1 0 0 0-.48-.853L18 11`, `M6 4.933V21`, and the circle cx 12, cy 9, r 2.
  - `baby`: `M10 16c.5.3 1.2.5 2 .5s1.5-.2 2-.5`, `M15 12h.01`, `M19.38 6.813A9 9 0 0 1 20.8 10.2a2 2 0 0 1 0 3.6 9 9 0 0 1-17.6 0 2 2 0 0 1 0-3.6A9 9 0 0 1 12 3c2 0 3.5 1.1 3.5 2.5s-.9 2.5-2 2.5c-.8 0-1.5-.4-1.5-1`, `M9 12h.01`.
  - The source file carries Lucide's ISC notice verbatim.
- **Tokens:** `--school-marker` → fixed `#5a6b7b`; `--child-care-marker` → fixed `#1c9099`. Never a theme-token fallback. Both join `CLAUDE.md`'s fixed-color exceptions.
- **Labels:** `locationTypeLabel?(type, signal?)`, then the feature's `type_label`, then `mapsdk_location_type_unknown` ("Location"). Never the raw type code.
- **Zoom:** every zoom by default. `zoomRange` passes through to `pointsPlugin`.
- **Not selectable.** No `lat`/`lng` lookups anywhere.
- **Every UI string is a `mapsdk_*` key** in `en.json`, with no concatenated sentences. Numbers go through `format.number`. Nothing module-global. Code style: tabs, double quotes, no trailing commas, width 100, runes only.
- **Before each commit under `src/lib`:** `npm run lint && npm run check && npm test && npm run test:bundle`. Run `npm run test:licenses` once Task 2 lands.
- **No Claude or AI attribution.** Push and PR, merge, and the release each need the user's yes.

## Review Focus

1. **A focus point on a school inside a count bubble:** the focus row stays (the school isn't drawn on its own), and it drops once the bubble splits at a higher zoom. Pinned in Task 4.
2. **Labels arriving after the first draw:** rows and cards show `type_label` first, then switch to the metadata label without a reload. Pinned in Task 6.
3. **The host replaces the source's features** (the dashboard re-fetches for a new region): old schools leave the list, and a pinned card on a removed school closes. Pinned in Task 6.
4. **Nullable fields:** `city`, `school_district`, `grade_span`, `enrollment` and `capacity` are null or missing. Their card lines are left out, never shown as "null" or "0". An enrollment of `0` is shown. Pinned in Task 6.
5. **Two schools at the same coordinates** (shared campuses are common): both are listed, the badge draws once on top, and the focus row drops if either is drawn. Pinned in Tasks 4 and 6.
